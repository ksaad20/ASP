# [0.1.0] - Initial MVP

The first public release of **Autonomous Synthesis Planner**.

## Added

### Core Software

* Initial project structure
* Modular package architecture
* Python package configuration
* Command-line interface
* Python API
* Documentation framework

### Chemistry

* Molecular parsing framework
* Molecular representations
* Reaction data structures
* Template management foundation

### Planning

* Retrosynthesis engine
* Route generation framework
* Search infrastructure
* Route scoring
* Route optimization foundation

### Visualization

* Route visualization module
* Planning summaries
* Export framework

### Development

* Unit testing
* Continuous Integration
* Static type checking
* Code formatting
* Linting
* Documentation

# Release Philosophy

Autonomous Synthesis Planner follows an incremental development model.

Each release aims to:

* Maintain backward compatibility whenever practical.
* Improve reproducibility.
* Expand synthesis planning capabilities.
* Improve software quality.
* Increase documentation coverage.
* Strengthen automated testing.
